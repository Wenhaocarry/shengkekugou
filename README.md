# 声刻计划 H5 · V5

本仓库发布当前 V5 源码，`master` 为发布分支，并支持 Vercel 浏览器演示版。本地记录、上传媒体、缓存与运行截图不进入 Git。首次克隆建议运行 `./start.sh -expand-playlist-demo` 生成完整示例歌单。线上部署及 Vercel 兼容性见 [部署说明](docs/部署说明.md)。

V5 从已保存的 V4 独立创建。当前 V5.2 使用用户「封面图片 2」提供的 14 张原始 PNG 和星空背景，三张图片纵向 3D 层叠，上下滑动可双向循环。每张图显示对应记录歌曲的歌名和歌手。点击图片后，在同一画面中展示心情、文字、照片和标签。整个 App 采用 720×1558 设计画布，按屏幕宽高等比缩放；右上角可切换到日历、歌曲时间轴、声刻环。播放器菜单中保留原声刻入口。V4 已另存于 [v4-stable](https://github.com/Wenhaocarry/shengkekugou/tree/v4-stable) 分支和本地 `../shengke-v4/`。设计见 [V5 设计说明](docs/V5设计说明.md)。

## Vercel 浏览器演示

运行 `npm run build` 生成 `dist/`，或在 Vercel 导入本仓库，使用 `master`、Other 框架和仓库根目录。构建和输出目录已在 `vercel.json` 中配置，无需云数据库。记录、照片、上传歌曲保存于各自浏览器的 IndexedDB，不上传到服务器、不跨设备同步；清除站点数据会删除记录，可使用 JSON/ZIP 备份保存。

## 本地 Go 版启动

双击 `启动声刻.command`，或在本目录运行：

```sh
./start.sh
```

访问 **http://127.0.0.1:8101/**。V4 使用 8100，V3 使用 8099，V2 使用 8098，各版本使用各自的 `data/`，可以分别启动。

需要 Go 1.22+；没有第三方 Go 依赖，也不需要 npm 安装。前端文件随 Go 程序嵌入，修改页面后重新运行启动脚本。

## 布局与入口

- **首页**：顶部频道与搜索、继续播放横幅、个人入口、横向推荐卡、三列专属歌单；下方固定浅蓝迷你播放器和“首页 / 直播 / 会员 / 福利 / 我的”导航。中间三个入口按参考保留外观，点击无操作。
- **播放队列**：点击迷你播放器或全屏播放器右侧的列表图标，打开酷狗式底部面板，包含正在播放、单曲足迹、歌单足迹、当前歌曲高亮、喜欢、队列移出及底部顺序/编辑/最近/收起操作。移出只影响本页队列，不删除音乐库或声刻；足迹记录本次页面会话。
- **我的**：浅蓝渐变背景、白色资料卡、音乐生活与声刻入口、常用功能、横向最近播放、我的歌单。
- **播放器**：全屏封面、深蓝渐变、顶部四页切换、歌曲信息、操作栏、进度和播放控制。四页分别为音乐故事、封面、歌词、歌曲相关；歌词可点按定位，数据使用实际保存的声刻记录。
- **声刻**：记录创建、编辑、删除、多图、心情和场景、日期时间、位置、可见范围、日历、时间轴、声刻环、图片预览和原图保存及重听均保留。弹窗和记录卡统一为蓝白视觉。
- **分享**：卡片和轻量心情两种格式、四种主题、实时图片预览、系统分享和保存图片。默认海盐主题。

| 地址 | 页面 |
| --- | --- |
| `/#home` | 首页（默认） |
| `/#player` | 沉浸式播放器 |
| `/#mine` | 我的 |
| `/#favorites` | 我喜欢的音乐 |
| `/#memories` | 我的声刻 |
| `/#settings` | 设置、添加本地歌曲、导出与备份 |

推荐卡和播放列表使用现有音乐库，不替换用户上传的音频、封面或记录。图中的商业歌曲和真实酷狗会员服务并未接入；现有示例歌曲仍播放原创合成演示音频。

## 数据与接入边界

本地数据从 V4 独立复制，状态和全部媒体逐文件校验。各本地版本之后独立保存，不自动同步。线上 V5 沿用 V3 的 IndexedDB 数据库名称和结构，同一域名、同一浏览器已保存的记录继续保留；不重新导入示例覆盖记录。

当前仍为本地单用户 Demo。“公开 / 好友 / 私密”保留所选属性；正式权限、酷狗登录和微信原生分享需要宿主接入。完整导出和 ZIP 备份在设置中。更多已有接入说明见 `docs/接口与接入.md`。
