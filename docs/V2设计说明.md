# V2 设计说明

版本日期：2026-09-14。以用户提供的 `Frame 2147221425.png` 设计长图为视觉依据；Figma 链接当前未成功读取，因此不声称像素级还原 Figma 源稿。

## 已落地

**范围约束：仅调整 UI 和布局，保留 V1 功能、业务规则和已有数据。** 播放、喜欢气泡及频控、歌曲切换、记录增删改、图片上传、更多/自定义标签、时间/可见范围、日历/时间轴/声刻环、重听、导出备份等能力不变。入口合并及弹窗重排仅属于展示层变化。

- 播放页：单一主要声刻入口，沉浸封面、青蓝渐变、轻量操作区和柔和圆形播放按钮。
- 记录页：奶油色横线纸、手写感正文、胶带及照片贴纸；保留真实创建、编辑、图片和标签功能。
- 底部弹窗：统一标题、关闭/返回、分隔线和底部操作；发布成功在底部弹窗内展示。
- 标签：统一的柔和彩色 SVG 图标；保留更多、自定义、心情单选和场景最多三个。
- 相册：作为情绪轨迹的同级页面展示；照片支持放大、保存，以及回到对应的情绪轨迹记录。
- 歌单：白色酷狗式列表、细分隔和紧凑歌曲信息；标题和播放器固定，只滚动中间列表。
- 分享：同页选择类型、切换四种卡片主题、查看实际生成的预览并保存；不再反复进入预览页面。

## 版本与数据

V1 位于同级 `shengke-v1/`，包括源代码、可执行程序和当时的数据。只排除可再生成的运行缓存和临时锁，复制后已做校验。V2 在 `shengke/` 中继续开发，沿用原有数据，不自动清空或迁移字段。

主预览仍使用 8098 端口。测试发布使用独立临时数据，未写入主预览的数据目录。

## 接入边界

此版本仍是单用户演示 H5。微信按钮在支持文件分享的浏览器里调用系统分享，否则提示保存图片后手动发送；未接入酷狗/微信原生 SDK。示例歌曲音频及客户端入口边界保持不变。
