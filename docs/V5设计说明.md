# V5 · 会呼吸的封面墙

V5 从已归档的 V4 独立创建。进入「我的 → 声刻记忆」时，直接看到全屏封面墙；画面由三列错落的歌曲封面组成，中央当前歌曲亮度更高、位置更靠前，侧列更暗。左右滑动使用浏览器原生滚动、贴合定位和逐帧视差，触屏、鼠标拖动、左右方向键及上一张/下一张按钮均可切换。手机宽度完全贴边，桌面横向展开，不再套加宽的手机外框。

轻触当前封面时，中心图片先放大，周围图像收暗；随后记录内容从画面下方渐显，与封面处于同一个视图。定格后仍可看到主图、记录时间、心情、文字、照片、场景、位置和编辑/新增入口。记录较多时，只滚动内容区；关闭后回到同一首歌曲的封面墙。点击记录照片继续使用原图预览和单图保存，返回时保留当前展开状态。

右上角视图按钮打开已有的日历、歌曲时间轴和声刻环；可以从该视图切回封面墙。播放器右下歌曲选项中的原声刻入口、角标和功能保持不变。浏览器版沿用 `shengke-browser-v3` IndexedDB；本地 Go 版使用本目录独立 `data/`，默认端口 8101。静态构建只使用干净示例，绝不打包本地记录和媒体。

验证：`./test.sh`、记忆标签测试、静态构建和隔离 Chrome UI 回归。UI 回归覆盖原有记录/照片/音频/备份流程、封面墙拖拽与触滑、键盘切换、同页展开、三种回顾视图、播放、360/390/430 像素及横屏/桌面布局、空记录与浏览器数据库沿用。真机手势与 Vercel 线上部署另行检查。
