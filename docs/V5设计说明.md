# V5 · 会呼吸的封面墙

V5 从已归档的 V4 独立创建。V5.2 认可版本已保存为 `v5.2-stable-20261022`，后续可以回退。当前 V5.3 保留三张纵向 3D 层叠封面和上移后的构图，重做同屏记忆展示。整个 App 采用 720×1558 设计画布，现有界面在 360×779 的逻辑网格中渲染两倍，所有页面按同一倍率适配屏幕。宽度或高度受限时整体等比缩小，桌面保持竖屏比例，外部为浅色留白。顶层弹窗使用同一倍率和画布边界，滚动和图片展开坐标也按同一倍率换算。

图片使用用户「封面图片 2」目录中的 14 张原始 PNG，按字节复制，未重新生成或裁切。`web/memory-covers-v2/sources.json` 记录原文件名与 SHA-256。V5.3.1 起首页、播放器、歌词背景、队列、记录页与声刻画廊统一使用这组素材，同一首歌曲与封面保持稳定映射。旧素材路径保留以兼容已打开的旧页面。每张卡片显示对应记录的歌曲标题和歌手，不改写用户已保存的歌曲信息。

滑动使用浏览器原生纵向滚动和吸附，支持触屏、鼠标拖动、滚轮及上下方向键。只渲染三张交互图片；接近滚动区域首尾时平移到等价循环位置，保持图片与相位不变，实现双向连续浏览。没有自动播放，用户停手后聚焦最近一张。背景使用 SVG 星空，叠加缓慢明暗变化；系统减少动态效果时关闭闪烁。

每张图片都是独立入口。点哪张，就从原位置先放大，再显露唱片和记忆票笺，背景带一点封面本身的环境色。封面移动用 Web Animations 的 transform 关键帧，记录渐显、心情落章、文字显影和照片落纸分阶段出现。定格后展示记录时间、心情、文字、照片、场景、位置和编辑/新增入口。横滑或使用上/下一段按钮翻阅同一首歌的记忆，唱片随之轻转；长记录竖向阅读。关闭时从当前动画位置反向回到原封面，途中关闭或切换视图会取消旧动画。全程不跳转详情页面，不自动播放。

手势只接管明确的横向拖动，纵向滚动留给浏览器；横滑后抑制误点击照片。非当前记录设置 inert，当前票笺可获得键盘焦点，左右方向键翻阅。系统减少动态效果时直接显示定格内容。点击照片继续使用原图预览和单图保存，返回后保留当前记录。

记忆票笺采用深蓝底与浅色文字，日期、心情、位置标签和照片相框同步使用深色配色，与星空背景衔接。

右上角视图按钮打开已有的日历、歌曲时间轴和声刻环；可以从该视图切回封面墙。播放器右下歌曲选项中的原声刻入口、角标和功能保持不变。浏览器版沿用 `shengke-browser-v3` IndexedDB；本地 Go 版使用本目录独立 `data/`，默认端口 8101。静态构建只使用干净示例，绝不打包本地记录和媒体。

验证覆盖原有记录/照片/音频/备份流程，以及三张渲染、原图路径、歌名和歌手、纵向拖拽与触滑、上下键切换、两个循环边界、关闭后位置恢复、三种回顾视图、各尺寸画布比例和弹窗边界、空记录与浏览器数据库沿用。`gallery-motion.test.cjs` 在普通动画模式检查分段放大、翻页和原记录对应、横滑/竖滑、反向收起、中途取消、照片/位置、长记录和手机/桌面边界，生成隔离测试预览。真机触感尚未验证。
