# V5 · 会呼吸的封面墙

V5 从已归档的 V4 独立创建。进入「我的 → 声刻记忆」时，画面由三列大小错落的歌曲封面组成，图片间留有窄缝，列之间有轻微的透视和视差。左右滑动使用浏览器原生滚动，支持触屏、鼠标拖动和方向键。页面沿用 V3 的手机宽度规则，最多 430 像素；手机内贴边，电脑上保持竖屏宽度。首屏移除了歌曲标题、说明、翻页和播放控制，图片占满顶栏下方空间。

每张封面都是独立入口。点哪张，就从该图片原来的位置放大，周围图像收暗；随后对应歌曲的记录从下方渐显，与图片处于同一个视图。定格后展示主图、记录时间、心情、文字、照片、场景、位置和编辑/新增入口。记录较多时，只滚动内容区；关闭后回到原来的封面墙位置。点击记录照片继续使用原图预览和单图保存，返回时保留当前展开状态。

右上角视图按钮打开已有的日历、歌曲时间轴和声刻环；可以从该视图切回封面墙。播放器右下歌曲选项中的原声刻入口、角标和功能保持不变。浏览器版沿用 `shengke-browser-v3` IndexedDB；本地 Go 版使用本目录独立 `data/`，默认端口 8101。静态构建只使用干净示例，绝不打包本地记录和媒体。

验证覆盖原有记录/照片/音频/备份流程，以及封面墙拖拽与触滑、键盘切换、点击图片与对应记录、同页展开、三种回顾视图、360/390/430 像素及横屏/桌面的宽高边界、空记录与浏览器数据库沿用。截图逐尺寸检查；真机触感尚未验证。
