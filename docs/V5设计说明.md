# V5 · 会呼吸的封面墙

V5 从已归档的 V4 独立创建。当前 V5.1 使用三张纵向 3D 层叠图片：中间图片正面清晰、靠前；上下两张缩小、倾斜并退入空间。上下滑动时，图片沿立体路径转换前后位置。页面沿用 V3 的手机宽度规则，最多 430 像素；手机内贴边，电脑上保持竖屏宽度。首屏只有顶栏和图片。

图片使用用户「封面图片」目录中的 13 张原始 PNG，按字节复制，未重新生成或裁切。`web/memory-covers/sources.json` 记录原文件名与 SHA-256。声刻画廊固定使用这组素材，不再被歌曲上传时附带的封面替换。歌曲与封面保持稳定映射。

滑动使用浏览器原生纵向滚动和吸附，支持触屏、鼠标拖动、滚轮及上下方向键。只渲染三张交互图片；接近滚动区域首尾时平移到等价循环位置，保持图片与相位不变，实现双向连续浏览。没有自动播放，用户停手后聚焦最近一张。

每张图片都是独立入口。点哪张，就从该图片原来的位置放大，周围图像收暗；随后对应歌曲的记录从下方渐显，与图片处于同一个视图。定格后展示主图、记录时间、心情、文字、照片、场景、位置和编辑/新增入口。记录较多时，只滚动内容区；关闭后回到原来的循环位置。点击记录照片继续使用原图预览和单图保存，返回时保留当前展开状态。

右上角视图按钮打开已有的日历、歌曲时间轴和声刻环；可以从该视图切回封面墙。播放器右下歌曲选项中的原声刻入口、角标和功能保持不变。浏览器版沿用 `shengke-browser-v3` IndexedDB；本地 Go 版使用本目录独立 `data/`，默认端口 8101。静态构建只使用干净示例，绝不打包本地记录和媒体。

验证覆盖原有记录/照片/音频/备份流程，以及三张渲染、原图路径、纵向拖拽与触滑、上下键切换、两个循环边界、点击图片与对应记录、关闭后位置恢复、同页展开、三种回顾视图、360/390/430 像素及横屏/桌面的宽高边界、空记录与浏览器数据库沿用。原图 SHA-256 校验通过；真机触感尚未验证。
