# PDF 页面与当前实现

本项目以用户提供的《声刻计划-校招 MINI 项目文档》为产品与视觉依据，不另外扩展首页、章节、成长体系或独立四栏导航。

| PDF 设计 | 实现 |
| --- | --- |
| 播放页左上角返回键旁的声刻入口 | 加号 / 最近图片 / 心情与记录数；进入创建或本曲历史 |
| 轻气泡提醒 | 行为触发、自动收起、浏览器本地频控 |
| 创建音乐记忆 | 白色半屏面板，换歌、文本、图片、位置、心情、场景、可见范围、时间及蓝色发布按钮 |
| 各选项独立面板 | 单选心情、最多 3 场景、最多 3 图片；支持自定义心情和场景 |
| 发布完成 | 自动关闭创建面板、返回播放页、顶部成功提示及分享入口 |
| 我喜欢的音乐 | 深蓝歌单、歌曲旁浅金色标签、独立点击查看历史 |
| 我的入口 | 蓝色酷狗外壳，听歌时长 / 乐签 / 声刻回忆并列，底部迷你播放器与宿主导航 |
| 我的声刻 | 深蓝云朵标题区、白色内容区；日历 / 时间轴 / 声刻环；再记一笔 |
| 单曲与单条记忆 | 白色历史列表、详情、编辑、删除确认和重听 |
| 分享 | 微信状态·轻量分享 / 声刻卡片·完整分享；内容预览、系统分享或图片下载 |

## 视觉处理

使用 PDF 的蓝白配色与页面组织，播放器插画和照片取自 PDF，仅调整字体、间距、圆角及手机安全区。原文档位图分辨率有限，正式上线建议换用设计源文件的高清素材。

## 真实能力和演示边界

记录读写、字段校验、多图持久化、回顾统计和卡片生成由本项目真实实现。日历、时间轴和声刻环读取实际记录，不把静态设计稿数字作为用户数据。

酷狗“我的”、歌单和播放器外壳是演示入口，不代表已接入宿主帐号、收藏列表或付费能力。会员、直播等非课题功能仅提示演示边界，不扩展实现。正式接入需要客户端提供 JSBridge、身份和分享协议，具体见《接口与接入》。

保留此前用户记录；不为视觉还原重置数据。示例音频为合成音，页面标有“示例音频”。
