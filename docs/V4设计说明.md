# V4 · 音乐里的每一个你

2026-10-21。V4 以 V3 的最终版本为基础独立创建。旧版代码和数据保留。

## 播放器

左上角的圆形声刻入口收进右下“⋯ / 歌曲选项”。保留原来 30 px 圆形按钮、心情图标或记忆照片和右上数量角标，只移动位置；有记录时查看该曲记忆，无记录时创建第一段记忆。原有底部记一笔和声刻操作继续可用。

## 封面海

“我的”增加深色封面卡入口；进入声刻后默认打开封面海。仅展示有真实记录的歌曲，每张封面使用真实记忆文字、日期和计数，不制造历史。方形封面来自用户提供的 13 张素材，网页使用约 223 KB 的 WebP 版本，原 PNG 保留在原素材目录；用户自己的歌曲封面优先使用。素材用于记忆展示，不作为真实唱片封面来源声明。

2026-10-22 调整：默认以 174 px 小封面叠层展示，前后错位、轻微旋转，随滚动连续更新 3D 位置。页面沿用应用最大 430 px 宽度，不再扩成独立大画布。右上角的小图标可切换叠层与原有展开封面，切换保留选中歌曲；从“我的”重新进入默认叠层。

触屏使用原生惯性滑动与吸附，鼠标支持拖动；拖动后不会误打开记录。也支持左右按钮、方向键、Home/End。减少动态效果设置下不使用程序化平滑滚动。点侧封面选中，点中间封面或“翻开这首歌的记忆”进入单曲轨迹，返回保留所选封面。封面播放键播放/暂停选中歌曲，底部播放器显示实际播放歌曲。

日历、歌曲时间轴、只看有图、声刻环、照片预览、原图保存和分享仍可访问。空记录页面展示开始记录入口，不展示虚构记录。

## 数据与验证

线上沿用 `shengke-browser-v3` IndexedDB 和原结构，保持已有记录及媒体。静态构建仍只读取干净示例，不读取本地 `data/`。本地 V4 数据由 V3 独立复制，逐文件 SHA-256 校验；默认端口为 8100。

验证通过：Go test、Go vet、记忆标签测试；隔离 Chrome 回归覆盖 V3 既有完整流程，以及菜单收纳、封面滚动/键盘/循环切换、选歌播放与返回、手机/横屏/桌面布局、空集合和 IndexedDB 名称兼容。未执行手机真机测试。
