# V3 设计说明

2026-10-20。视觉与布局依据用户提供的六张酷狗音乐手机截图，包括推荐首页、我的、音乐权益/故事、封面播放器、歌词、歌曲相关。

## 布局

首页使用浅蓝渐变顶区，保留频道、搜索、播放横幅、个人信息、两张大推荐卡与右侧小卡、三列歌单、固定迷你播放器及底栏的排列关系。首页卡片连接实际音乐库、收藏歌单和声刻记录。

我的页面采用白色资料大卡、徽章、音乐生活入口、听歌与声刻统计、快速记录卡、五个常用入口、横向最近播放和歌单。保留累计听歌、乐签及声刻入口。

播放器采用顶部页签圆点、全屏封面、深蓝渐变和固定底部控制区。四页为音乐故事、封面、歌词、歌曲相关。歌词点按定位并跟随进度高亮；相关页展示本地歌曲信息、实际记忆天数、条数和照片数。参考图中的会员购买、音效服务和外部榜单不虚构为可用功能。

记忆创建、历史、详情、相册和分享面板统一为蓝白组件，保留已有字段、图片、主题和全部操作。默认分享主题改为海盐，手账、落日、夜曲仍可切换。

根据第二次截图补充：首页与我的底栏统一为“首页 / 直播 / 会员 / 福利 / 我的”，中间三个未使用入口不响应点击。播放器右侧列表按钮打开约占屏幕下方 70% 的播放队列，顶部三栏、浅蓝提示条、来源信息和底部工具栏固定，中间歌曲独立滚动。队列支持选歌播放、当前歌曲蓝色高亮、喜欢、单条和批量移出；音乐库和声刻记录不随移出操作删除。足迹仅来自本次页面实际播放，避免伪造历史。

## 版本与数据

V3 目录与数据独立于 V2。创建时复制 `data/state.json` 与全部媒体，校验一致后开始开发；排除构建缓存、旧可执行文件、运行锁和日志。重新构建了含 V3 前端的程序，默认端口改为 8099。

原有记录业务逻辑、数据格式和 API 不变；补齐扩展歌单九首演示 WAV 文件的受限放行，修复这些歌曲原先无法从媒体接口播放的问题。已有示例音频及演示边界不变，不导入参考图中的商业录音。

## 验证

执行 Go vet、全量 Go 测试及 race 检测、记忆标签测试、JavaScript 语法检查。浏览器回归脚本使用独立临时数据，覆盖手机尺寸、播放、歌词、歌单固定布局、记录完整流程、三图、分享主题、回顾和相册，并保留预览截图。截图中的测试记录只存在于隔离测试环境。
