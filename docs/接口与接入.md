# 工程与接入说明

## 当前架构

浏览器 H5 → 同源 Go HTTP API → 原子 JSON 快照 + 媒体目录。

当前不接外部 AI、酷狗正式接口或支付。工程运行只需监听地址和数据路径；前端由 `web/kugou.js` 与 `web/kugou.css` 实现。

播放与记录分离：`web/bridge.js` 是当前的播放器适配接口，`getContext()` 返回歌曲与秒数，`playSong(id, position)` 发起定位播放。现在的实现指向本地 `<audio>`。界面业务仍主要使用本地播放器状态；它是集成起点，不意味着已经做到更换一个文件就可无缝接入酷狗。

## HTTP API

所有 JSON 字段使用 snake_case。错误返回 `{"error":"提示"}`。400 参数错误；404 不存在；409 关联保护；413 上传过大；403 跨站写入；500 服务端失败。

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | /api/health | 服务健康 / local-single-user |
| GET | /api/state | 当前完整状态 |
| POST | /api/songs | multipart 上传音频 |
| DELETE | /api/songs/{id} | 删除歌曲元数据；有关联记忆时 409 |
| PUT | /api/songs/{id}/lyrics | `{ "lrc": "[00:08.00]歌词" }` |
| POST | /api/photos | multipart 上传图片，返回 `{ "url": "/media/..." }` |
| POST | /api/memories | 创建记忆 |
| PUT | /api/memories/{id} | 替换原记忆字段，保留补刻和创建时间 |
| DELETE | /api/memories/{id} | 删除记忆与其补刻 |
| POST | /api/memories/{id}/replies | `{ "note": "今天想说", "date": "2026-09-08" }` |
| POST / PUT | /api/chapters[/{id}] | `{ "title": "章节", "description": "描述", "color": "#a6c8b8" }` |
| DELETE | /api/chapters/{id} | 删除章节，记忆解除归属但保留 |
| PUT | /api/settings | `{ "memory_hints": true, "demo_member": false }` |
| POST | /api/events | `{ "name": "memory_opened" }` 等允许的客户端事件 |
| GET | /api/export | JSON 档案下载 |
| GET | /api/backup | ZIP 完整备份，含当前状态引用的媒体 |
| GET / HEAD | /media/{file} | 音频/图片；支持 HTTP Range 拖动播放 |

歌曲 multipart 字段：`file`（必需）、`title`、`artist`、`duration`（秒，浏览器读取）、`color`、`cover_url`。照片先上传获得本地 URL，再关联到歌曲或记忆。

记忆创建/编辑字段：

```json
{
  "song_id": "歌曲 ID",
  "position": 92.5,
  "note": "今天终于准点下班了。",
  "mood": "被这句击中",
  "scenes": ["深夜戴耳机", "下雨天"],
  "location": "深圳",
  "visibility": "private",
  "date": "2026-09-08",
  "record_time": "21:35",
  "photo_urls": ["/media/已上传图片.jpg"],
  "photo_url": "",
  "chapter_id": ""
}
```

`photo_urls` 最多 3 张，必须是已上传的本地图片；`photo_url` 保留兼容旧单图数据。`record_time` 为可选的 `HH:mm` 时间。

歌曲和章节必须存在；位置不超过曲长；文字最多 1000 字，心情与每个场景最多 20 字；场景去重后最多 3 个；位置最多 80 字；`visibility` 只能是 `private`、`friends` 或 `public`。文字、心情和照片至少一项。客户端不能指定 ID、创建时间、示例属性或随意覆盖补刻。

## 真正接入酷狗，需要产品/研发提供什么？

1. **入口**：播放页按钮、歌词菜单、“我的”模块可以开放哪一种；H5 URL、灰度与路由规范。
2. **登录**：宿主登录态换取后端身份的正式协议、用户 ID、token 验签/续期规则；不能信任 URL 上随便传的 UID。
3. **歌曲身份**：稳定 song_id / hash、版本关系、标题、歌手、时长、封面、歌词及授权范围。本地临时 ID 后续需映射，不可用歌名当唯一键。
4. **播放器 SDK / JSBridge**：查询当前歌曲/秒数、订阅切歌与进度、跳转播放、生命周期、前后台行为。入口跳转携带秒数不等于持续同步能力。
5. **播放许可**：由宿主继续播放还是允许 H5 播放，会员歌曲/试听/版权地区的处理。不能直接提取下载地址绕过版权权限。
6. **分享**：宿主分享面板、深链和落地页白名单，访客权限与敏感信息确认。
7. **会员**：权益查询、试用和支付的正式接口；后端校验，不沿用本地模拟开关。
8. **数据/BI**：目标用户规模、重听率、播放页/歌词页流量、现有记录与分享行为（优先聚合脱敏）、可用实验人群与指标定义。不要为了做 Demo 获取无关个人历史。

集成步骤：先确认宿主协议 → 新增适配器与稳定歌曲模型 → 让宿主拥有播放控制权并禁用 H5 第二播放器 → 后端接身份和独立用户存储 → 联调秒数、切歌、背景状态 → 小流量验证提示打扰与留存。

## 上线前必须补齐

- 身份认证、按用户隔离与对象级权限；当前同一个服务是共享私人空间。
- PostgreSQL/MySQL 等正式数据库、迁移和对象存储，配额、上传限流、音频与图片完整解码校验、恶意文件处理、图片隐私处理。
- HTTPS、鉴权/CSRF 策略、安全审计、业务日志脱敏；当前只有基础同源写保护与 CSP。
- 备份/恢复演练、媒体生命周期和删除策略；目前保留旧媒体，不保证账号级彻底删除。
- 无障碍、移动 WebView/各类音频编码、错误与离线、真实歌曲版权/会员状态联调。
- 多端冲突处理、自动化迁移、监控告警、真实实验和 BI 口径。

## 当前 H5 路由与宿主入口

- `/#player`：默认落地页，模拟酷狗播放页和左上角声刻入口。
- `/#favorites`：我喜欢的音乐，展示由真实记录生成的轻量回忆标签。
- `/#memories`：声刻回忆，包含日历、时间轴和声刻环。
- `/#mine`：酷狗“我的”外壳，包含“听歌时长 / 乐签 / 声刻回忆”三栏。技术设置中的导出和备份仅供本地演示使用。

酷狗入口可以直接配置 H5 的 `/#player`。正式接入时，建议宿主通过 JSBridge 提供当前 `song_id` 和播放秒数，H5 后端完成登录态换票后再读取该用户的记忆；不要把 UID 或记忆内容直接放在 URL 查询参数中。
